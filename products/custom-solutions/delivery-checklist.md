# Project Delivery Checklist
## Discovery
- [ ] Verify buyer, decision maker, business goal, and budget.
- [ ] Document scope, exclusions, security/privacy requirements, and acceptance criteria.
- [ ] Sign SOW and confirm deposit before starting paid work.

## Build
- [ ] Create isolated development environment.
- [ ] Use synthetic data during prototyping.
- [ ] Implement minimal permissions and secret management.
- [ ] Log errors without exposing sensitive data.
- [ ] Add human override and fallback behavior.

## Validate
- [ ] Test normal, edge, and failure cases.
- [ ] Test accessibility, performance, and mobile if applicable.
- [ ] Confirm integration access and data retention.
- [ ] Obtain client acceptance in writing.

## Handover
- [ ] Deliver code/docs and admin instructions.
- [ ] Transfer credentials securely via client-managed systems.
- [ ] Confirm billing, support, and maintenance ownership.
- [ ] Schedule 30-day outcomes review if contracted.
